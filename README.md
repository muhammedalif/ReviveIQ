# ReviveIQ — The CPR Monitor

> A high-performance, real-time CPR timing and event recorder for ACLS resuscitation teams.

**Developed by Dr. Muhammed Alif**  
Consultant Anaesthesiologist & Intensivist  
Founder, HealthionX Medical Solutions

---

## Features

- ⏱ Real-time CPR elapsed timer
- ⚡ Shock logging with joule entry
- 🫀 Rhythm check logging (shockable / non-shockable)
- 💉 Drug administration log with timestamping
- 🔔 Auto-reminders:
  - Rhythm check every **2 minutes**
  - Adrenaline every **4 minutes** (alternate rhythm checks, per AHA ACLS)
- 📋 Full timestamped event log
- 🖨 Print / PDF export of resuscitation record
- 📱 Progressive Web App — installable on iOS, Android, and desktop
- ✈️ Works fully offline after first load

## Deploy to GitHub Pages

1. Fork or clone this repo
2. Go to **Settings → Pages**
3. Set source to **GitHub Actions**
4. Push to `main` — the workflow deploys automatically
5. Access at `https://<your-username>.github.io/<repo-name>/`

Or enable Pages manually:
- Settings → Pages → Source: Deploy from branch → Branch: `main` → Folder: `/ (root)`

## Clinical Notes

- Adrenaline reminder interval: **4 minutes** (every alternate rhythm check)
- Rhythm check reminder: **2 minutes**
- Based on **AHA ACLS 2020/2025 guidelines**
- For use by **trained medical professionals only**
- Always follow institutional protocols and team leader directives
