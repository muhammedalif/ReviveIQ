Real-time Code Blue monitoring for the Timer-Recorder in a High-Performance Resuscitation Team. Tracks shocks, rhythm checks, drugs, and Chest Compression Fraction (CCF) live.

CCF logic: Code Blue clock = denominator. Compression time only accumulates when "Start compressions" is pressed. CCF drops in real time when compressions are paused.

Adrenaline: every 4 min (alternate rhythm checks). Rhythm check: every 2 min. CCF target: ≥80%. 15s advance warnings for all intervals. Based on AHA ACLS guidelines.

⚠ For trained medical professionals only. Always follow institutional protocols and team leader directives.

Reset session?

All timers, counters, CCF data, and the event log will be cleared. This cannot be undone.
